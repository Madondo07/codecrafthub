# CodeCraftHub

CodeCraftHub is a small Spring Boot REST API for tracking courses you want to learn. It is designed as a beginner-friendly way to practice HTTP methods, JSON requests and responses, validation, and REST endpoints.

## Features

- Create, list, retrieve, update, and delete courses.
- Store course data in `courses.json`; no database is required.
- Generate course IDs starting at `1` and creation timestamps automatically.
- Validate required fields, ISO dates, and allowed course statuses.
- Create `courses.json` automatically on the first application launch.

Each course has this JSON shape:

```json
{
  "id": 1,
  "name": "Spring Boot REST APIs",
  "description": "Learn to build REST endpoints with Spring Boot.",
  "target_date": "2026-12-15",
  "status": "Not Started",
  "created_at": "2026-11-02T10:30:00Z"
}
```

The API accepts these exact status values: `Not Started`, `In Progress`, and `Completed`. `id` and `created_at` are generated by the server. They are preserved during updates and any values supplied for them in a request are ignored.

## Requirements

- Java Development Kit (JDK) 25 or later
- Apache Maven 3.6.3 or later

Check that both are available:

```powershell
java -version
mvn -version
```

## Installation

Clone or download the project, then open a terminal in the folder containing `pom.xml`. Maven downloads the required Spring Boot dependencies the first time you build or run the project.

```powershell
mvn clean install
```

## Run the Application

Start the API from the project directory:

```powershell
mvn spring-boot:run
```

The API is available at `http://localhost:8080`. On startup, the application creates `courses.json` in its working directory if it does not already exist. The initial file contains an empty JSON array (`[]`). Keep this file if you want to retain your course data between runs.

To build and run the packaged application instead:

```powershell
mvn clean package
java -jar target/codecrafthub-0.0.1-SNAPSHOT.jar
```

## API Endpoints

All endpoints use the base path `http://localhost:8080/api/courses` and send/receive JSON.

| Method | Path | Description | Success response |
| --- | --- | --- | --- |
| `POST` | `/api/courses` | Add a course | `201 Created` with the course |
| `GET` | `/api/courses` | Get all courses | `200 OK` with an array |
| `GET` | `/api/courses/{id}` | Get one course | `200 OK` with the course |
| `PUT` | `/api/courses/{id}` | Replace a course's editable fields | `200 OK` with the updated course |
| `DELETE` | `/api/courses/{id}` | Delete a course | `204 No Content` |

The `name`, `description`, `target_date`, and `status` fields are required for both `POST` and `PUT`. `target_date` must be a date in `YYYY-MM-DD` format.

### Add a Course

```powershell
curl.exe -i -X POST http://localhost:8080/api/courses `
  -H "Content-Type: application/json" `
  -d '{"name":"Spring Boot REST APIs","description":"Learn REST basics with Spring Boot.","target_date":"2026-12-15","status":"Not Started"}'
```

The response has status `201 Created`, includes a `Location` header for the new course, and returns a body similar to:

```json
{
  "id": 1,
  "name": "Spring Boot REST APIs",
  "description": "Learn REST basics with Spring Boot.",
  "target_date": "2026-12-15",
  "status": "Not Started",
  "created_at": "2026-11-02T10:30:00Z"
}
```

### Get All Courses

```powershell
curl.exe http://localhost:8080/api/courses
```

An empty collection is returned as `[]`.

### Get One Course

```powershell
curl.exe http://localhost:8080/api/courses/1
```

If the ID does not exist, the API returns `404 Not Found` with an error body such as `{"error":"Course with id 1 was not found"}`.

### Update a Course

`PUT` replaces the course's editable fields, so include all four required fields:

```powershell
curl.exe -i -X PUT http://localhost:8080/api/courses/1 `
  -H "Content-Type: application/json" `
  -d '{"name":"Spring Boot REST APIs","description":"Build and test REST APIs.","target_date":"2027-01-15","status":"In Progress"}'
```

The server keeps the original `id` and `created_at` values. If the ID does not exist, the API returns `404 Not Found`.

### Delete a Course

```powershell
curl.exe -i -X DELETE http://localhost:8080/api/courses/1
```

Successful deletion returns `204 No Content` with no response body. Deleting an unknown ID returns `404 Not Found`.

## Troubleshooting

### `mvn` is not recognized

Install Apache Maven and add its `bin` directory to your `PATH`. Open a new terminal and confirm `mvn -version` works. Also confirm Java 25 or later is available with `java -version`.

### The application cannot start because port 8080 is in use

Stop the other process using port 8080, or start this application on another port:

```powershell
mvn spring-boot:run "-Dspring-boot.run.arguments=--server.port=8081"
```

Then use `http://localhost:8081` for API requests.

### A request returns `400 Bad Request`

Check that the request has a valid JSON body and `Content-Type: application/json`. Include all required fields, use `YYYY-MM-DD` for `target_date`, and use one exact status value: `Not Started`, `In Progress`, or `Completed`.

### A request returns `404 Not Found`

Verify that the course ID exists. `GET`, `PUT`, and `DELETE` return this status when there is no course with the requested ID.

### Course data is missing or the API reports a file error

The file is resolved relative to the application's working directory, which is normally the project folder when started with `mvn spring-boot:run`. Check that `courses.json` is present there and is valid JSON. The app needs permission to read and write the file and its containing directory. Back up the file before editing it manually.

### Maven cannot download dependencies

Check your network connection and Maven repository access, then retry `mvn clean install`. The first build needs to download Spring Boot and its dependencies.
